# Homework 1

依作業簡報的數學定義實作兩題，使用 C++11。程式與報告由本次題目重新撰寫，沒有複製提供的 GitHub 範例內容。

| 檔案 | 內容 |
| --- | --- |
| [p1.cpp](p1.cpp) | Ackermann 函數的遞迴與非遞迴版本 |
| [p2.cpp](p2.cpp) | 遞迴產生冪集合 |
| [report.md](report.md) | 解題說明、正確性、複雜度與測試 |

## 編譯與執行

```sh
g++ -std=c++11 -Wall -Wextra -pedantic p1.cpp -o p1
g++ -std=c++11 -Wall -Wextra -pedantic p2.cpp -o p2
```

Windows 執行 `./p1.exe` 與 `./p2.exe`，Linux/macOS 執行 `./p1` 與 `./p2`。

第一題輸入 `3 4`，兩個版本都輸出 `125`。示範介面接受 `0 <= m <= 3`、`0 <= n <= 6`。

第二題先輸入元素個數，再輸入不同的元素，例如 `3 a b c`。會印出 8 個子集合，`{}` 代表空集合。元素以空白分隔，區分大小寫，最多 16 個。
